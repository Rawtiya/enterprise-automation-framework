# Automation Opportunity Assessment

## 1. Objective

The Automation Opportunity Assessment evaluates a business process to determine:

- Whether the process should be automated
- What type of automation may be appropriate
- The expected business value
- Implementation feasibility
- Operational and compliance risks
- Priority relative to other opportunities

---

## 2. Process Information

| Field | Description |
|---|---|
| Process Name | Name of the business process |
| Business Function | Function / department |
| Process Owner | Accountable process owner |
| Process Volume | Transactions per period |
| Frequency | Daily / Weekly / Monthly |
| FTE Effort | Current manual effort |
| Cycle Time | Current process cycle time |
| Error Rate | Current error / defect rate |
| Exception Rate | Percentage requiring manual intervention |
| Systems | Applications involved |
| Customer Impact | Low / Medium / High |
| Compliance Impact | Low / Medium / High |

---

## 3. Process Excellence Assessment

Before automation, assess whether the process should be redesigned.

### Eliminate

Can any activities be removed?

### Simplify

Can steps, approvals, handoffs, or decisions be reduced?

### Standardize

Is there a consistent process across teams or locations?

### Automate

Which remaining activities are suitable for automation?
